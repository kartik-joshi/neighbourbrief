Methodology

How we count

Every number in a NeighbourBrief bulletin is computed by code from open data. The AI only writes sentences around those numbers, and nothing can be published until every number, in every language, matches.

See the whole process in one diagram

What a number means

  • Reports to police, not proven crimes. A report does not mean anyone was charged.
  • Counted by the date the report was made, in Toronto time, not the date it happened. Report dates don't change later, so the numbers are stable.
  • One per occurrence and category. An incident with several victims counts once in each category it falls under.
  • Month = the last complete calendar month. Year to date = January 1 to the end of that month, compared with the same days last year.

Rules that keep it fair

  • Small numbers: a percent change is shown only when both counts are {{ small }} or more. Otherwise we show the two counts ("12 vs 9"), because a jump from 2 to 4 isn't a "100% increase" anyone should worry about.
  • Shootings and homicides: counts only, never a percent change.
  • Not included: {{ excluded|join(', ') }} (sensitive, and no comparable history in the open data).
  • No rankings, maps of incidents, predictions or "dangerous" labels. Places are never compared with each other.
  • No personal information. Bulletins show only contact details the police publish for residents.

How numbers are checked

  • Every number in the English text must be one the code computed (or one the officer typed).
  • Each category line may only use its own category's numbers.
  • Each translated line must carry exactly the same numbers as its English line, and a percentage must stay a percentage.
  • Each translation must use the right alphabet for its language (for example, no Hindi letters in Urdu).
  • Each translation is read back in English, and every line must still go the same direction ("down" can't become "up").
  • If any check fails, publishing is blocked until it's fixed or a person confirms a manual review.

Check any number yourself. Each neighbourhood profile and each bulletin's numbers file links every count to a query on the Toronto Police Service open data portal that returns the same number (distinct reports per category, by report date in Toronto time).

Data sources

  • Toronto Police Service Public Safety Data Portal (Open Government Licence – Ontario): {{ layers|join(', ') }}.
  • City of Toronto Neighbourhood Profiles, 2021 Census (mother tongue), for suggested languages.
  • Every bulletin offers "The numbers behind this bulletin" as a spreadsheet (CSV).

Translations

Translations are AI-assisted and say so on every page until a human translator has reviewed them. Numbers are protected during translation and re-checked afterwards.
