Accessibility statement

NeighbourBrief aims to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA, which is above what Ontario's AODA requires of public-sector websites (WCAG 2.0 AA).

What we do

  • Every page is tested automatically with axe-core, on desktop and phone widths, before each release. The current release has no violations.
  • Keyboard: a "Skip to main content" link on every page, visible focus, and arrow keys between language tabs.
  • Bulletins come in a large-print version and print on one Letter page each in regular print.
  • Right-to-left languages (Urdu, Arabic, Pashto, Persian) are laid out right to left, with fonts made for their scripts.
  • Charts have a text description and a table with every number; colour is never the only signal.
  • Plain language: bulletins are written for about a Grade 6 reading level.

Known limits

  • Translations are AI-assisted and say so on every page; a human review partner is being sought.
  • The neighbourhood map uses OpenStreetMap tiles; the same information (boundary and services) is listed in text next to it.

Tell us about a problem

If something on this site is hard to use, please tell the community group that shared it with you, or open an issue on the project's code repository. We aim to reply within 5 business days.
